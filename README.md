
# Experimental Umbrella Sampling

This repository contains supplementary Jupyter notebooks and Python code for data analysis and figure generation accompanying the bioRxiv preprint:

**Experimental umbrella sampling of a rotary nanomachine**  
L. J. K. Weiss, L. Daubner, N. Tedeschi, P. Šulc, and F. C. Simmel  
*bioRxiv* (2026)  
**DOI:** [10.64898/2026.10.15.758702](https://doi.org/10.64898/2026.10.15.758702)

The analysis relies on the Python package [`roboarmanalysis`](https://github.com/matvogt/roboarmanalysis), developed by Matthias Vogt.
